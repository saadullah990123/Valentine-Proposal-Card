# 💌 Valentine Proposal Card

A playful, fully responsive "Will you be my Valentine?" web card — the No button dodges your cursor so you can only click Yes 😄. Built with HTML, CSS, and JS.

# ✨ Features
 🎯 Interactive "No" button that dodges the cursor/touch
 📱 Fully responsive — works on mobile, tablet, and desktop
 🎨 Smooth animations and modern gradient UI
 💳 Optional flow: date agreement / confirmation card

# 🛠️ Tech Stack
 HTML5
 CSS3 (Flexbox, Grid, clamp() for responsive scaling)
 Vanilla JavaScript
